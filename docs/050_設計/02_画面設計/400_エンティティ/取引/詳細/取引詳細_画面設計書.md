## 2. 機能概要

- 取引 1 件の ID、Date、Description、Amount、Bank Account、Label を読み取り専用で表示する。
- 表示するデータは、ルートのリゾルバー `operationResolve` が `GET api/operations/{id}` で取得する。取得結果はコンポーネントの `input` である `operation` に入る。画面のコンポーネント自身は API を呼ばない。
- Bank Account と Label は、取得した取引に一緒に含まれる関連である。バックエンドは `GET api/operations/{id}` の時点で両方を読み込んで返すため、この画面は関連のために追加の API を呼ばない。
- Bank Account は銀行口座詳細へのリンク、Label はラベル詳細へのリンクとして表示する。銀行口座詳細の User のように文字だけで表示する項目ではない。
- 取得に失敗して 404 のときは `/404` へ、その他の失敗のときは `/error` へ遷移し、この画面は表示しない。
- 「Back」ボタンでブラウザーの履歴を 1 つ戻る。「Edit」ボタンで取引編集画面へ遷移する。
- 入力項目はない。この画面に `入力チェック一覧` はない。
- `<jhi-alert-error />` と `<jhi-alert />` を置く。

## 3. 画面レイアウト

画面は `Main` の `<router-outlet />` の中に表示される（`src/app/layouts/main/main.html`）。テンプレートは中央寄せの `<div class="d-flex justify-content-center">` と `<div class="col-8">` で囲み、その中の `@if (operation(); as operationRef)` が真のときに次の領域を上から順に表示する。

```
見出し領域（<h2 data-cy="operationDetailsHeading">）
    Operation
    <hr />
アラート領域
    <jhi-alert-error />   … エラー
    <jhi-alert />         … 成功通知
明細領域（<dl class="row-md jh-entity-details">）
    ID           … id
    Date         … date（日時の書式で整形）
    Description  … description
    Amount       … amount
    Bank Account … bankAccount.name（銀行口座詳細へのリンク）
    Label        … ラベル名へのリンク（カンマ区切り）
ボタン領域
    [Back] [Edit]
```

| 領域 | テンプレート上の要素 | 表示条件 | 4 章の対応 |
| --- | --- | --- | --- |
| 見出し領域 | `<h2 data-cy="operationDetailsHeading">`、`<hr />` | `operation()` が `null` でないとき | `### 見出し領域` |
| アラート領域 | `<jhi-alert-error />`、`<jhi-alert />` | 同上（アラートがあるときだけ内容が表示される） | `### アラート領域` |
| 明細領域 | `<dl class="row-md jh-entity-details">` | 同上 | `### 明細領域` |
| ボタン領域 | Back ボタン、Edit ボタン | 同上 | `### ボタン領域` |

## 5. イベント処理

### 5.1 イベント一覧

| No. | イベント発生源 | イベント | 遷移先 | イベント物理名 |
| --- | --- | --- | --- | --- |
| 1 | 画面 | 初期化（この画面への遷移。ルートの解決） | データがなければ `/404` または `/error` | `operationResolve`（`OperationService.find()`） |
| 2 | Back ボタン | クリック | ブラウザーの履歴の前の画面 | `previousState()` |
| 3 | Edit ボタン | クリック | `/operation/:id/edit` | `[routerLink]="['/operation', operationRef.id, 'edit']"` |
| 4 | Bank Account のリンク | クリック | `/bank-account/:id/view` | `[routerLink]="['/bank-account', operation()!.bankAccount?.id, 'view']"` |
| 5 | Label のリンク | クリック | `/label/:id/view` | `[routerLink]="['/label', label.id, 'view']"` |

### 5.2 イベント詳細

#### 5.2.1 画面初期化

- トリガー: `/operation/:id/view` への遷移。画面が表示される前に、ルートガードとリゾルバーが順に動く。
- 処理手順:
  1. ルートガード `userRouteAccessService` が `AccountService.identity()` でアカウントを確認する。未ログインなら遷移前の URL を `StateStorageService.storeUrl()` で保存し、`/login` へ遷移してここで終わる。
  2. リゾルバー `operationResolve(route)` が `route.params` から `id` を取り出す。`id` があれば `inject(Router)` と `inject(OperationService)` を取得し、`service.find(id)` を呼ぶ。`id` がなければ `of(null)` を返す。
  3. `OperationService.find(id)` は `GET api/operations/{id}` を送る（`id` は `encodeURIComponent` でエンコードする）。応答は `convertResponseFromServer()` を通り、`date` が dayjs オブジェクトに変換される。
  4. 成功なら `IOperation` がそのままリゾルバーの戻り値になる。失敗なら `catchError` が `HttpErrorResponse` を受け、`status` が 404 のときは `router.navigate(['404'])` を、それ以外のときは `router.navigate(['error'])` を実行して `EMPTY` を返す。`EMPTY` のためこの画面への遷移は完了しない。
  5. 解決結果は、ルート定義の `resolve` のキー `operation` と同じ名前の `input`（`readonly operation = input<IOperation | null>(null)`）に入る。これは `src/app/app.config.ts` の `provideRouter` に指定した `withComponentInputBinding()` によるものである。
  6. テンプレートは `@if (operation(); as operationRef)` の中身を表示する。
- 状態変化: `operation`（`input`）に取得結果が入る。コンポーネントは他の状態を持たない。
- 遷移: 通常はなし。4. の失敗時のみ `/404` または `/error` へ遷移する。

#### 5.2.2 Back ボタンクリック

- トリガー: `(click)="previousState()"`。
- 処理手順: `previousState()` は `globalThis.history.back()` を呼ぶだけである。画面内に状態はない。
- 状態変化: なし。画面が破棄されるとき `<jhi-alert />`（`Alert`）の `ngOnDestroy()` が `alertService.clear()` を呼ぶ。
- 遷移: ブラウザーの履歴を 1 つ戻る。遷移先は履歴による（取引一覧から来たなら取引一覧に戻る）。この画面を直接開いて履歴がなければ、コードからは遷移先を確認できない。

#### 5.2.3 Edit ボタンクリック

- トリガー: `[routerLink]="['/operation', operationRef.id, 'edit']"` のクリック。
- 処理手順: 取引編集画面（`/operation/:id/edit`）へ遷移する。遷移先でも同じリゾルバー `operationResolve` が `GET api/operations/{id}` を送る。
- 状態変化: なし（画面が破棄される）。
- 遷移: `/operation/:id/edit`。

#### 5.2.4 関連のリンククリック（Bank Account、Label）

- トリガー: Bank Account のリンク（`[routerLink]="['/bank-account', operation()!.bankAccount?.id, 'view']"`）、Label のリンク（`[routerLink]="['/label', label.id, 'view']"`）のクリック。
- 処理手順: Bank Account は銀行口座詳細画面、Label はラベル詳細画面へ遷移する。Label のリンクは `operationRef.labels` の要素の数だけあり、それぞれ要素の `label.id` をパスに使う。
- 状態変化: なし（画面が破棄される）。
- 遷移: `/bank-account/:id/view`、`/label/:id/view`。

### 5.3 API呼び出し一覧

この画面に関わる API 呼び出しは、ルートの解決のときにリゾルバーが送る 1 件だけである。画面のコンポーネントは API を呼ばない。

| No. | 目的 | メソッド | パス | 要求パラメーター | 応答 | 成功時 | エラー時 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 表示データの取得（ルートの解決） | GET | `api/operations/{id}` | パスパラメーター `id`（ルートの `:id`。`encodeURIComponent` でエンコードする） | 200: `IOperation` 1 件（`id`、`date`、`description`、`amount`、`bankAccount`、`labels`） | リゾルバーが `IOperation` を返し、`operation`（`input`）に入る | 404 のときリゾルバーが `/404` へ遷移する。その他の失敗のときは `/error` へ遷移する。どちらも `EMPTY` を返し、この画面は表示されない |

補足:

- 呼び出し元はリゾルバー `operationResolve`（`src/app/entities/operation/route/operation-routing-resolve.service.ts`）で、メソッドは `OperationService.find(id)`（`src/app/entities/operation/service/operation.service.ts`）である。`find()` は応答を `convertResponseFromServer()` で変換し、`date` の文字列を dayjs オブジェクトにする。
- バックエンドは `OperationResource.getOperation(id)`（バックエンドの `src/main/java/io/github/jhipster/sample/web/rest/OperationResource.java`）である。`operationRepository.findOneWithEagerRelationships(id)` を呼び、結果は `ResponseUtil.wrapOrNotFound(operation)` で返り、値がなければ 404 になる。銀行口座詳細の `BankAccountResource.getBankAccount(id)` が読み込む関連はユーザー 1 つだが、取引は銀行口座とラベルの 2 つを別々のクエリーで読み込む（バックエンドの `src/main/java/io/github/jhipster/sample/repository/OperationRepository.java`、`OperationRepositoryWithBagRelationshipsImpl.java`）。
- 要求ヘッダーは `authInterceptor` が `Authorization: Bearer <トークン>` を付ける（トークンがあるとき）。バックエンドは `/api/**` に認証を要求する（バックエンドの `src/main/java/io/github/jhipster/sample/config/SecurityConfiguration.java`）。
- 401 のときは `authExpiredInterceptor` が現在の URL を `StateStorageService.storeUrl()` で保存し、ログアウトして `/login` へ遷移する。

### 5.4 画面遷移

| 遷移先 | 条件 | トリガー |
| --- | --- | --- |
| 取引編集（`/operation/:id/edit`） | ログインしていること | Edit ボタン |
| 銀行口座詳細（`/bank-account/:id/view`） | `operation.bankAccount` が設定されていること | Bank Account のリンク |
| ラベル詳細（`/label/:id/view`） | `operationRef.labels` の要素の `label.id` を使う | Label のリンク |
| ブラウザーの履歴の前の画面 | 履歴があること | Back ボタン（`previousState()`） |
| 404 画面（`/404`） | `GET api/operations/{id}` が 404 を返した | リゾルバー `operationResolve`（`router.navigate(['404'])`） |
| エラー画面（`/error`） | `GET api/operations/{id}` が 404 以外の失敗を返した | リゾルバー `operationResolve`（`router.navigate(['error'])`） |
| ログイン（`/login`） | 未ログインのままこの画面を開いた | `userRouteAccessService`（遷移前の URL を `StateStorageService.storeUrl()` で保存してから遷移する） |
