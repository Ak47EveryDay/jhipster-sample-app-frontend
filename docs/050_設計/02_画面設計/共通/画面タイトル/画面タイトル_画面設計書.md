## 2. 機能概要

- ナビゲーションが完了するたびに、遷移先のルートに設定された `title`（翻訳キー）を翻訳し、ブラウザーのタイトルに設定する。
- 処理は Angular の `TitleStrategy` を継承した `AppPageTitleStrategy` が担う。`appConfig` の providers で `TitleStrategy` として登録する（`src/app/app.config.ts`）。
- タイトルは文字列ではなく翻訳キーで指定する。翻訳は `TranslateService.get()` で行う。
- ルートに `title` がない場合は、親ルートの `title` を使う。どのルートにも `title` がなければ、既定の翻訳キー `global.title`（「JhipsterSampleApplication」）を使う。
- 言語が変わったときは、`Main` がタイトルを読み直す（`src/app/layouts/main/main.ts`）。
- 画面タイトルの部品は API を呼ばない。

## 3. 画面レイアウト

この部品は画面を持たない。タイトルの決まり方は次のとおりである。

```
ナビゲーションの完了
    → Angular が TitleStrategy.updateTitle(routerState) を呼ぶ
        → buildTitle(routerState)        … 遷移先のルートの title（翻訳キー）。なければ親ルートの title
        → なければ 'global.title'
        → translateService.get(翻訳キー)
        → title.setTitle(翻訳された文言)   … ブラウザーのタブに表示される
```

| 構成要素 | ファイル | 役割 | 4 章の対応 |
| --- | --- | --- | --- |
| タイトルの設定 | `src/app/app-page-title-strategy.ts` | ルートの `title` を翻訳してブラウザーに設定する | `### タイトルの設定` |
| タイトルの定義 | 各ルート定義ファイルの `title` | 翻訳キーでタイトルを指定する | `### ルートごとのタイトル` |

## 5. イベント処理

### 5.1 イベント一覧

| No. | イベント発生源 | イベント | 遷移先 | イベント物理名 |
| --- | --- | --- | --- | --- |
| 1 | ルーティング | ナビゲーションが完了する | なし | `AppPageTitleStrategy.updateTitle(routerState)` |
| 2 | 画面外（言語の変更） | 言語が変わる | なし | `Main` の `translateService.onLangChange`（購読）から `titleStrategy.updateTitle(...)` |

### 5.2 イベント詳細

#### 5.2.1 ナビゲーションの完了

- トリガー: ルーティングによってアクティブなルートが変わること。
- 処理手順:
  1. Angular が登録された `TitleStrategy` の `updateTitle(routerState)` を呼ぶ（Angular の標準の動きであり、本リポジトリのコードではない）。
  2. `buildTitle(routerState)` で、遷移先のルートの `title` を得る。`buildTitle()` は Angular が用意するメソッドであり、主アウトレットのルートの連鎖のうち、いちばん深い（遷移先に近い）`title` を返す。
  3. 結果が `undefined` なら `'global.title'` にする。
  4. `translateService.get(pageTitle)` を購読し、届いた翻訳文を `this.title.setTitle(title)` でブラウザーに設定する。
- 状態変化: ブラウザーのタイトル（`document.title`）。
- 遷移: なし。
- 補足: 名前付きアウトレット（`navbar`）には `title` がない。`src/app/app.routes.ts` の `path: ''`、`outlet: 'navbar'` のルートは、主アウトレットのタイトルに影響しない。

#### 5.2.2 言語が変わったとき

- トリガー: `translateService.use()` によって言語が変わり、`onLangChange` が流れること。
- 処理手順: `Main.ngOnInit()` が購読している `onLangChange` の中で `this.titleStrategy.updateTitle(this.router.routerState.snapshot)` を呼び、今の画面のタイトルを新しい言語で設定し直す。
- 状態変化: ブラウザーのタイトル。
- 遷移: なし。
- 補足: 現在は `LANGUAGES` が `'en'` の 1 つだけであるため、実際に言語が変わるかどうかはコードからは確認できない（[国際化_画面設計書](../国際化/国際化_画面設計書.md) 参照）。

### 5.4 画面遷移

該当なし。この部品を起点とする遷移はない。

### 5.5 利用箇所

- `AppPageTitleStrategy` を登録しているのは `src/app/app.config.ts` の `{ provide: TitleStrategy, useClass: AppPageTitleStrategy }` だけである。
- `TitleStrategy` を使っているのは `appConfig` の登録と `Main`（`src/app/layouts/main/main.ts`）だけである。
- ナビゲーションバーのルート（`outlet: 'navbar'`）を除く全ルートで動く。

### 5.6 内部構造

- `AppPageTitleStrategy` は `TranslateService` と `Title` を注入する（`src/app/app-page-title-strategy.ts`）。
- `Title` サービスは `appConfig` の providers に `Title` として登録されている（`src/app/app.config.ts`）。
- 翻訳キーが見つからないときの文言は、国際化の未定義キーの処理により `translation-not-found[<キー>]` になる（[国際化_画面設計書](../国際化/国際化_画面設計書.md) 参照）。
