## 2. 機能概要

- アプリケーションの入り口になる画面である。ルート `/` に対応する。
- 見出し、サブタイトル、ログイン状態に応じた案内、JHipster 関連の外部リンクを表示する。
- 画面のコンポーネント自身は API を呼ばない。表示の分岐に使うのは `AccountService` の読み取り専用シグナル `account` である。その値はページフレーム `Main` が `AccountService.identity()` で取得する。
- ログイン中は、ログイン中のユーザーのログイン ID を埋め込んだ成功アラートを表示する。
- 未ログインのときは、ログインを促す警告アラートと、アカウント登録を促す警告アラートの 2 つを表示する。
- 外部リンクは 6 つあり、いずれも新しいタブで開く。
- 入力項目はない。この画面に `入力チェック一覧` はない。
- `<jhi-alert />` も `<jhi-alert-error />` も置いていない。

## 3. 画面レイアウト

画面は `Main` の `<router-outlet />` の中、`<div class="card jh-card">` の内側に表示される（`src/app/layouts/main/main.html`）。テンプレートのルートは `<div class="row">` で、左にイラスト、右に本文を置く。

```
イラスト領域（<div class="col-md-3">）
    <span class="hipster img-fluid rounded">     … 背景に画像を敷く
本文領域（<div class="col-md-9">）
    見出し領域（<h1 class="display-4">）
        Welcome, Java Hipster! (Jhipster Sample Application)
    サブタイトル領域（<p class="lead">）
        This is your homepage
    ログイン状態案内領域                        … account() で分岐
        ログイン中:  You are logged in as user "{{username}}".            … 成功アラート
        未ログイン:  If you want to sign in, you can try the default accounts: ...
                     You don't have an account yet?  Register a new account     … 警告アラート 2 つ
    リンクリスト領域
        If you have any questions on JHipster:
        - JHipster homepage / JHipster on Stack Overflow / JHipster bug tracker
        - JHipster public chat room / follow @jhipster on Twitter
    スターリンク領域（<p>）
        If you like JHipster, don't forget to give us a star on GitHub!
```

| 領域 | テンプレート上の要素 | 表示条件 | 4 章の対応 |

| イラスト領域 | `<div class="col-md-3">` の中の `<span class="hipster img-fluid rounded">` | 常に | `### イラスト領域` |

## 5. イベント処理

### 5.1 イベント一覧

| No. | イベント発生源 | イベント | 遷移先 | イベント物理名 |
| --- | --- | --- | --- | --- |
| 1 | 画面 | 初期化（画面を開いたとき。アカウントの状態が変わったときも表示が追従する） | なし | なし（コンポーネントに初期化処理はない。ページフレームの `Main.ngOnInit()` に依存する） |
| 2 | sign in リンク | クリック | `/login` | `login()` |
| 3 | Register a new account リンク | クリック | `/account/register` | `routerLink="/account/register"` |
| 4 | 外部リンク 6 つ | クリック | なし（外部サイトを新しいタブで開く） | `href`、`target="_blank"` |

### 5.2 イベント詳細

#### 5.2.1 画面初期化

- トリガー: `/` への遷移。コンポーネント `Home` はライフサイクルのメソッドを持たず、フィールド `account` に `inject(AccountService).account` を代入するだけである。
- 処理手順:
  1. ページフレーム `Main`（`src/app/layouts/main/main.ts`）の `ngOnInit()` が `this.accountService.identity().subscribe()` を呼ぶ。`AccountService.identity()` は、キャッシュ（`accountCache$`）がなければ `GET api/account` を送る。
  2. 取得に成功すると `AccountService.authenticate()` が呼ばれ、シグナル `account` に `Account` が入る。
  3. 取得に失敗しても購読側には `null` が流れるだけで、シグナル `account` は変わらない（初期値は `null`）。この場合は未ログインとして扱われる。
  4. `Home` の `account` は `AccountService` の読み取り専用シグナルそのものである。値が変わるとテンプレートの `@if (account(); as accountRef)` が再評価され、ログイン状態案内領域の表示が切り替わる。
- 状態変化: 画面自身は状態を持たない。シグナル `account`（`AccountService`）の値によって表示が変わる。
- 遷移: なし。
- 補足: 画面のコンポーネントもルートのリゾルバーも API を呼ばないため、この文書に 5.3 API呼び出し一覧 はない。`GET api/account` の呼び出し方は [アカウント状態と認証_画面設計書](../../共通/アカウント状態と認証/アカウント状態と認証_画面設計書.md) に、応答の内容は `03_IF設計/02_電文レイアウト/認証_電文レイアウト.md` に書く。

#### 5.2.2 sign in リンククリック

- トリガー: `(click)="login()"`。
- 処理手順: `login()` は `this.router.navigate(['/login'])` を呼ぶだけである。遷移先の `/login` にはルートガードがない。
- 状態変化: なし（画面が破棄される）。
- 遷移: `/login`（ログイン画面）。

#### 5.2.3 Register a new account リンククリック

- トリガー: `routerLink="/account/register"` のクリック。
- 処理手順: 登録画面へ遷移する。ルートは `src/app/account/register/register.route.ts` の `path: 'register'`（親は `src/app/account/account.route.ts` を読み込む `src/app/app.routes.ts` の `path: 'account'`）であり、ルートガードはない。
- 状態変化: なし（画面が破棄される）。
- 遷移: `/account/register`（登録画面）。

#### 5.2.4 外部リンククリック

- トリガー: リンクリスト領域の 5 つとスターリンク領域の 1 つ、合わせて 6 つの `<a>` のクリック。
- 処理手順: アプリケーションは何もしない。リンクは `href` に外部の URL を持ち、`target="_blank"` と `rel="noopener noreferrer"` を指定しているため、ブラウザーが外部サイトを新しいタブで開く（HTML の属性の指定であり、本リポジトリのコードによる処理ではない）。
- 状態変化: なし。
- 遷移: アプリ内の遷移はない。この画面は表示されたままになる。

### 5.4 画面遷移

| 遷移先 | 条件 | トリガー |
| --- | --- | --- |
| ログイン（`/login`） | 未ログインのときに表示される sign in リンク | `(click)="login()"` |
| 登録（`/account/register`） | 未ログインのときに表示される Register a new account リンク | `routerLink="/account/register"` |
| 外部サイト（アプリ内の遷移はない） | 常に表示 | `<a href="https://www.jhipster.tech/" target="_blank">` など 6 つのリンク |
