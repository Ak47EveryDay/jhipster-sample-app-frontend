## MOCK/替身手法

HTTP 通信は Angular の `@angular/common/http/testing` の `HttpTestingController` + `provideHttpClientTesting()` で捉え、`httpMock.expectOne({ method, url })` で要求を検証し `flush()` で応答を返す。テスト終了時に `httpMock.verify()` で未消化要求を検査する（`src/app/entities/bank-account/service/bank-account.service.spec.ts`）。サービス依存は `TestBed.configureTestingModule` の providers で `useValue` のモックに置換する（`src/app/core/auth/account.service.spec.ts` の `StateStorageService`、`src/app/layouts/main/main.spec.ts` の `AccountService`）。戻り値の差し替えは `vi.spyOn(...).mockReturnValue(of(...))`、時刻制御は `vi.useFakeTimers()` / `vi.advanceTimersByTime()`（`src/app/core/util/alert.service.spec.ts`）、スパイは `vi.spyOn`（`src/app/entities/operation/update/operation-update.spec.ts`）。モーダルは `NgbModal.open` を spy し、`closed` Subject でダイアログの確定を再現する（`src/app/entities/admin/user-management/list/user-management.spec.ts`）。E2E では実ブラウザ + dev サーバ + 実バックエンド（`npm run e2e:headless` が `wait-on` で 8080 ポートの起動を待つ、`package.json`）。
