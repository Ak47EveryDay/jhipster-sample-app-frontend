## 测试目录结构

単体テスト（`*.spec.ts`）はテスト対象と同じディレクトリに置く（例：`src/app/entities/operation/service/operation.service.spec.ts`）。テストデータは `*.test-samples.ts` に `sampleWithRequiredData` / `sampleWithNewData` / `sampleWithPartialData` / `sampleWithFullData` として定義し、各 spec から import する（`src/app/entities/admin/user-management/service/user-management.service.spec.ts`）。E2E は `cypress/e2e/{account,administration,entity}/*.cy.ts`、共通サポートは `cypress/support/`（`commands.ts`、`entity.ts`、`navbar.ts` 等）、Cypress 用 tsconfig は `cypress/tsconfig.json`。
