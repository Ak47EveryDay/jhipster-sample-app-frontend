## 扩展点

- ルート駆動の画面追加：`src/app/app.routes.ts` / `src/app/entities/entity.routes.ts` に `loadComponent` / `loadChildren` で遅延読込ルートを追加する。
- 翻訳：`src/i18n/en/*.json` の翻訳キーで文言を定義し、テンプレートは `jhiTranslate` ディレクティブ（`src/app/shared/language/translate.directive.ts`）で参照する。言語は現在 `en` のみ（`src/app/config/language.constants.ts`）。
- 権限による表示分岐：`HasAnyAuthorityDirective`（`src/app/shared/auth/has-any-authority.directive.ts`、`*jhiHasAnyAuthority`）とルート `data.authorities`。
- ビルド時定数：`SERVER_API_URL`（`src/app/config/endpoint.constants.ts` の `serverApiUrl`）によりバックエンド URL を差し替え可能（`README.md`）。
- Service Worker（`provideServiceWorker('ngsw-worker.js', { enabled: false })`、`src/app/app.config.ts`）とルート `title` / `TitleStrategy`（`src/app/app-page-title-strategy.ts`）は設定により挙動が変わる。
