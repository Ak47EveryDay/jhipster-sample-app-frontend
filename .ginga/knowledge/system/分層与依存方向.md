## 分層与依存方向

機能層（`src/app/home/`、`src/app/login/`、`src/app/account/`、`src/app/admin/`、`src/app/entities/`、`src/app/layouts/`）→ 共通部品層（`core`：auth / interceptor / request / util、`shared`：alert / auth / date / filter / jhipster / language / pagination / sort）→ 設定層（`src/app/config/`）の順にのみ下位を参照する。設定層は他の `src/app` 配下を参照しない。`core` から機能層を参照する例外は `src/app/core/interceptor/auth-expired.interceptor.ts`（HTTP 401 時に `LoginService.logout()` を呼ぶ）1 件のみ。`core` と `shared` は互いに参照しあうが、`core` から `shared` への参照は `app/shared/jhipster/` 配下の定数・純関数に限る（出典：`docs/050_設計/02_画面設計/000_アプリ/アプリ/アプリ_画面設計書.md` 3.2）。
