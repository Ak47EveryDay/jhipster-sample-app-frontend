## 数据与事件契约

契约（バックエンド ⇔ フロントエンドの HTTP 電文）：パスは `${serverApiUrl}api/...` と `${serverApiUrl}management/...`（出典：`docs/050_設計/03_IF設計/02_電文レイアウト/README.md`）。主な API グループ：認証 `api/authenticate`、アカウント `api/account` 系、ユーザー管理 `api/admin/users`、権限 `api/authorities`、銀行口座 `api/bank-accounts`、ラベル `api/labels`、取引 `api/operations`、管理 `management/info|configprops|env|health|loggers|jhimetrics|threaddump` と `api/users`（出典：`docs/050_設計/01_一覧/05_API呼び出し一覧.md`）。一覧取得は `httpResource`（Angular のシグナル連動再要求）を使うものと `HttpClient` の `query()` を使うものがある。モデル（DTO）は `src/app` 配下の `*.model.ts` に型定義され、`RestOf<T>` で日付フィールドを REST 表現（`toJSON()`）へ変換する（`src/app/entities/operation/service/operation.service.ts` の `RestOperation` 型など）。アラート契約：成功通知はレスポンスヘッダー `X-jhipsterSampleApplicationApp-alert`（翻訳キー）と `X-jhipsterSampleApplicationApp-params`（ID 等）で運ばれ、`notificationInterceptor` が読む。エラーは Problem Details 本文（`message`、`fieldErrors[]`、`type`）とヘッダーのエラーキーで運ばれ、`AlertError` が `error.<キー>` の翻訳キーを表示する（出典：`docs/050_設計/01_一覧/04_メッセージ一覧.md` 3・6 章）。クライアント内イベント：`EventManager` による `jhipsterSampleApplicationApp.httpError` イベント配信（`errorHandlerInterceptor` → `AlertError`）。削除ダイアログ ⇔ 一覧画面は `ITEM_DELETED_EVENT` で完了通知（`src/app/config/navigation.constants.ts`、`src/app/entities/<entity>/delete/*-delete-dialog.ts`）。
